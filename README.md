# ckd-prediction-ml
# Machine learning model for early predication of chronic kidney disease using clinical data.

## Overview
This project uses machine learning techniques to predict whether a patient has chronic kidney disease based on medical attributes.

## Features
- Data preprocessing and cleaning
- Feature selection
- Model training and evaluation
- Prediction of disease outcome

## Tech Stack
- Python
- Scikit-learn
- Pandas
- NumPy

## Files
- ML_CKD.ipynb – main notebook

## How to Run
1. Open the notebook in Google Colab
2. Run all cells
